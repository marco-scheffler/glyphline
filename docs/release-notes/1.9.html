Glyphline tells you when an agent is waiting

With several Claude Code sessions open, the one that finished its turn and is quietly waiting for an answer looks exactly like the ones still working. Glyphline now notices when a session has been waiting on you for a few minutes and says so — whether or not a Glyphline window is open. Click the notification and the Agentverse opens.

Three minutes by default; Settings → Notifications lets you choose 1, 3, 5 or 10, or switch it off.

One thing it cannot know: a transcript looks the same whether the agent is asking you something or has simply finished. Both are reported.

A warning before a quota runs out

The quota rows already say "empty in 1h 40m" when a window will not last until it resets. Glyphline now also sends a notification when that moment is close — within half an hour, or within one sync interval if yours is longer — once per window and reset. Click it and the dashboard opens. This needs a Claude subscription signed in under Accounts.

Smaller

  • The menu bar shows Glyphline's own gauge instead of a stand-in symbol.
  • If a one-time correction ever recalculates your recorded usage, the dashboard now says so until you dismiss it, instead of leaving a step in your charts with no explanation.

The first notification asks macOS for permission. Requires macOS 26.
