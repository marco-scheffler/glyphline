A calmer menu bar

Three things the app was doing that it did not need to do.

The panel no longer rescrapes the web every time you open it

Reading a quota means loading an account's page in a web view and running a script against the rendered document — a real browser navigation, per account. The menu bar panel asked for one every time it opened, so with three accounts that was three page renders per click, on the thread that draws the panel you are standing in.

There is now a sixty second floor, far below the rate a five-hour or weekly window can move, and a scheduled refresh counts towards it.

It no longer re-asserts its activation policy on every open

Opening the panel re-set the app's activation policy even when it already was what the setting asked for. That turns a no-op into a real state change: macOS re-evaluates app activation underneath a panel that is in the middle of opening, which can make it flicker, close, or come back twice — and it is worse with more than one display.

The Agentverse stops drawing frames it cannot tell apart

The scene is computed from a frame counter that advances 60 times a second, but the animation ran at the display's refresh rate. On a 120 Hz screen every other frame rebuilt the entire scene and rasterised it to produce a picture identical to the one already on screen.

Measured at the window's real size, the datastream view costs 6.2 ms a frame with six sessions against an 8.3 ms budget at 120 Hz — so the half being discarded was the half that made it stutter.
