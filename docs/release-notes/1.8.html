Adding an account offers only what works

The Add Account sheet still offered OpenAI — selected by default — Cursor, a Claude admin key and local Claude Code logs. None of them has fed anything into Glyphline for several releases: an account added with any of them sat in the list showing nothing, with no hint why.

The sheet now asks for a name and opens the Claude sign-in. Accounts you added the old way are untouched, and deleting one still removes everything that belongs to it.

Agents that finish while no window is open

An agent reaches the break room when Glyphline sees it working and then sees it go quiet. Only the dashboard and the Agentverse window were looking, so in the menu bar — where neither opens on its own — an agent that started and finished while both were closed was never seen at all, and simply was not there when you opened the map.

Glyphline now looks every fifteen minutes, whether or not a window is open.

Deleted projects are no longer named

To read each Claude Code transcript only once, Glyphline remembers how far it got in each file, keyed by the file's path — and the path names the project. Claude Code deletes old transcripts on its own, so the record kept the names of projects long gone; on the machine this was found on, four in five entries.

Once a transcript is gone, its entry is now kept under a fingerprint of the path instead of the path. The entry itself has to stay: it is what stops a transcript you restore from a backup being counted a second time. This happens on the first scan after updating.

Smaller

  • If claude.ai ever routes signing in through a pop-up window, the pop-up now opens instead of doing nothing.
  • A failed quota check is no longer occasionally reported as an expired session, or the other way round, because of something loaded inside the page.

Requires macOS 26.
